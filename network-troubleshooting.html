Network Troubleshooting Guide

Updated: August 2025 • 12 min read

Overview: Practical solutions for common network issues. This guide covers Wi-Fi problems, connectivity issues, and network diagnostics.

1 Wi-Fi Connected but No Internet

FIX

Restart Your Router

Unplug the router for 30 seconds, then plug it back in. Wait 2 minutes for full restart.

FIX

Flush DNS Cache

Open PowerShell and run: ipconfig /flushdns

FIX

Check DNS Settings

Try using Google DNS (8.8.8.8) or Cloudflare (1.1.1.1) in your network adapter settings.

2 Slow Wi-Fi Speed

FIX

Check Signal Strength

Move closer to the router. Check signal strength in your device's Wi-Fi settings.

FIX

Scan for Interference

Other devices (microwaves, cordless phones) can interfere. Try changing your Wi-Fi channel.

FIX

Update Router Firmware

Check your router manufacturer's website for firmware updates.

3 Network Diagnostic Commands

Essential Network Commands

# Network Diagnostic Commands
# Author: Fekadu Wolde

# Test connectivity to Google
ping 8.8.8.8

# Trace the network path
tracert google.com

# View network adapter settings
ipconfig /all

# Display active connections
netstat -an

# Release and renew IP address
ipconfig /release
ipconfig /renew

# Test DNS resolution
nslookup google.com

# Test connection to a specific port
Test-NetConnection google.com -Port 80

Advanced Tips

  • Check for IP conflicts – Ensure no two devices have the same IP address.
  • Reset network stack – In PowerShell (Admin): netsh winsock reset
  • Consider a Wi-Fi analyzer app – To find the best channel and router placement.
